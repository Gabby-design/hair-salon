# Hair Masters Salon ✂️✨

A modern, high-contrast, multi-page boutique hair salon web application built for **Hair Masters Salon** located at **53b Euphrates Crescent, Wuse, Abuja, Federal Capital Territory, Nigeria**.

## 🌟 Key Features

- **High-Contrast Black Typography & Warm Ivory Palette**: Styled with `Instrument Serif` (headers) and `Work Sans` (body), warm ivory backgrounds (`#FBF8F5`), dusty rose accents (`#C88A80`), and sharp deep black/espresso text (`#1C1917`).
- **Multi-Page Architecture (`react-router-dom`)**:
  - `/` — **Home Page**: Hero section, boutique philosophy, featured services, client quotes, and studio highlights.
  - `/services` — **Salon Menu Page**: Comprehensive menu with category tabs (*Precision Cuts*, *Colour & Balayage*, *Treatments*, *Blowouts & Silk Press*, *Bridal*, *Kids*), detailed descriptions, durations, prices, and care advice.
  - `/about` — **Studio & Philosophy Page**: Story of Hair Masters Salon in Wuse, Abuja, senior stylist credentials, 24/7 care model, and amenities.
  - `/testimonials` — **Client Notes Page**: Interactive review slider, client quotes, and star ratings.
  - `/visit` — **Location & Hours Page**: Interactive directions, studio photo card, operating schedule, and 24/7 desk call link (`0817 344 5612`).
  - `/book` — **Interactive Booking Platform**: Live selected service card (`"This is the service you are booking for:"`), automatic query param pre-selection, full menu list breakdown, **"Auto-Fill My Details"** one-click feature, and instant WhatsApp booking link.
  - `/admin` — **Owner Service Management Portal**: Secure owner portal to add, edit, or delete salon services in real-time with `localStorage` persistence.

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Routing**: React Router DOM v7
- **Styling**: Tailwind CSS v3
- **Icons**: Lucide React

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/Gabby-design/hair-salon.git
cd hair-salon

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
